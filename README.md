# Projeto Tempo, Ondas e Observador

Investigação especulativa sobre a hipótese de que o tempo tem
estrutura ondulatória, e sobre possíveis assinaturas observáveis
dessa estrutura em dados cosmológicos e de Pulsar Timing Arrays.

**Autores:** Quickstar + Gepeto + Grokinha + Gemini + Deep (DeepSeek)
**Status:** Investigação especulativa em andamento
**Versão atual da documentação:** V5.2

---

## Aviso metodológico

Este projeto é composto por HIPÓTESES/IDEIAS ESPECULATIVAS,
não por uma teoria física estabelecida.

Regras que mantemos:
- não transformar coincidência em evidência;
- separar observação, dado, interpretação e hipótese;
- procurar primeiro padrões mensuráveis;
- tentar falsificar, não apenas confirmar;
- comparar com explicações convencionais antes de atribuir
  um fenômeno ao modelo;
- manter ideias concorrentes abertas.

A gaveta filosófica (documentação separada) inspira perguntas,
mas nunca substitui dados e testes.
